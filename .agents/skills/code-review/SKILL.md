## Boundary

### Always

- 리뷰를 시작하기 전에 `.agents/architecture/architecture-directory.md` 본문을 반드시 읽는다.
- `architecture-directory.md`가 참조하는 Architecture 문서는 현재 변경 범위에 해당하면 이어서 읽는다.
- 모듈 간 의존성, 공개 API, `api/internal` 경계가 포함되면 `.agents/architecture/conventions/spring-modulith.md`를 추가로 읽는다.
- 폴더 구조와 클래스 배치는 `architecture-directory.md`를 우선 기준으로 검토한다.

- 리뷰 대상과 기준 변경점을 먼저 식별한다.
- `.agents/domain/`, `.agents/architecture/`, `.agents/testing/`의 관련 규칙을 검토 기준으로 사용한다.
- 발견 사항은 재현 조건, 코드 위치, 근거와 영향을 함께 제시한다.
- 사용자 변경과 리뷰 범위 밖의 파일을 수정하지 않는다.

### Ask First

- 기준 브랜치나 리뷰 범위에 따라 결론이 달라지는데 범위가 불명확한 경우
- 외부 서비스, 자격 증명 또는 비용이 드는 검증이 필요한 경우
- 리뷰 중 발견한 문제를 직접 수정하도록 요청 범위를 확대해야 하는 경우

### Never

- 리뷰 요청만으로 코드, 테스트 또는 문서를 변경하지 않는다.
- 근거가 없는 가능성을 확정된 결함으로 보고하지 않는다.
- 단순 취향이나 스타일 차이를 결함으로 과장하지 않는다.
- 테스트 통과만으로 도메인 규칙과 회귀 위험 검토를 생략하지 않는다.

## Input Contract

- 리뷰할 변경, diff, 커밋 또는 코드 범위
- 변경의 목적과 기대 동작
- 관련 요구사항, 도메인 분석 또는 사용자 결정
- 이미 수행된 테스트와 검증 결과가 있다면 해당 정보

입력 형식은 제한하지 않지만 리뷰 대상과 변경 의도를 구분할 수 있어야 한다.

## Responsibilities

- 변경 범위와 주변 코드의 실행 맥락을 파악한다.
- 도메인 규칙, 상태 전이, 예외 흐름과 데이터 정합성 위반을 검토한다.
- 모듈 및 계층 경계, 공개 계약과 기존 동작의 회귀 가능성을 확인한다.
- 보안, 성능, 동시성 또는 운영 위험을 변경 내용에 비례해 검토한다.
- 테스트가 핵심 행위와 실패 경로를 충분히 보호하는지 판단한다.
- 발견 사항을 심각도와 영향 순서로 정리한다.

## Output Contract

다음 노드가 수정 필요성과 우선순위를 판단할 수 있도록 아래 정보를 전달한다.

- 심각도순 발견 사항과 정확한 코드 위치
- 각 발견 사항의 근거, 영향과 발생 조건
- 권장 수정 방향과 필요한 테스트
- 확인한 도메인·아키텍처·테스트 규칙
- 전제, 확인하지 못한 범위와 잔여 위험
- 발견 사항이 없는 경우 그 사실과 검증 한계
- 리뷰 완료 여부와 권장 다음 노드

Output은 다음 노드에 전달하며 별도 결과 파일로 저장하지 않는다.

## Verification Gate

- [ ] 리뷰 대상과 변경 의도를 확인했는가?
- [ ] 각 발견 사항에 위치, 근거, 영향이 포함되었는가?
- [ ] 도메인 규칙과 아키텍처 경계를 함께 검토했는가?
- [ ] 테스트 누락과 회귀 위험을 검토했는가?
- [ ] 추측과 확인된 결함을 구분했는가?
- [ ] Boundary를 위반하지 않았는가?

하나라도 충족하지 못하면 리뷰 완료로 전달하지 않는다.

## Failure Policy

- 리뷰 대상이나 기준 변경점을 확인할 수 없으면 필요한 정보만 요청하고 대기한다.
- 근거를 충분히 확인할 수 없는 의심 사항은 결함이 아닌 확인 필요 사항으로 전달한다.
- 테스트를 실행할 수 없으면 실행하지 못한 이유와 대체 검토 범위를 명시한다.
- 리뷰 중 수정이 필요해도 직접 변경하지 않고 구현 노드로 전달한다.

## Exit Criteria

- 완료: 검토 결과와 잔여 위험을 근거와 함께 Output으로 전달했다.
- 대기: 리뷰 범위나 검증 방법에 대한 사용자 결정이 필요하다.
- 실패: 리뷰 대상을 확인하거나 필수 검증을 완료할 수 없다.
- 취소: 사용자가 리뷰를 취소했다.
