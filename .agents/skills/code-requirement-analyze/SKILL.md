# Code Requirement Analyze

## Boundary

### Always

- 확정된 요구사항과 미해결 사항을 구분한다.
- `.agents/architecture/architecture-directory.md` 본문을 끝까지 읽는다.
- 관련 Architecture와 Testing 후보 문서의 frontmatter를 먼저 읽는다.
- 변경 범위와 관련된 Architecture와 Testing 문서 본문을 끝까지 읽는다.
- 관련 코드의 현재 구조와 실행 경로를 확인한다.
- 읽은 문서, 확인한 코드와 도출한 변경 범위를 기록한다.
- 확인된 사실과 기술적 추론을 구분한다.

### Ask First

- 확정되지 않은 도메인 규칙이 남아 있는 경우
- 변경 대상 모듈이나 공개 계약을 식별할 수 없는 경우
- 여러 구현 경로의 공개 계약이나 데이터 영향이 다른 경우
- 요청 범위를 넘는 구조 변경이 필요한 경우
- 데이터 삭제나 호환성 중단 가능성이 있는 경우

### Never

- 도메인 규칙을 새로 결정하거나 변경하지 않는다.
- 코드, 테스트, 문서와 마이그레이션을 생성하거나 수정하지 않는다.
- 근거 없이 구현 방식이나 변경 파일을 확정하지 않는다.
- 인프라 변경을 직접 수행하지 않는다.
- 미해결 요구사항을 구현 가능한 상태로 표시하지 않는다.

## Input Contract

- 사용자 요구사항 원문과 확정된 범위
- 확정된 도메인 규칙과 사용자 결정
- 누락, 모호와 충돌이 해소된 분석 결과
- 알려진 기술 제약과 보존할 공개 동작

확정 사항과 미해결 사항을 구분할 수 있어야 한다.

## Responsibilities

- 변경이 영향을 주는 모듈과 계층을 식별한다.
- 관련 공개 API와 모듈 경계를 식별한다.
- 현재 코드 구조와 재사용 가능한 구현 패턴을 확인한다.
- 변경 대상 코드와 보존할 코드를 구분한다.
- 요구사항별 코드 변경 책임을 연결한다.
- 계층별 테스트 범위와 필요한 검증 환경을 식별한다.
- Entity, Repository, 데이터베이스와 Flyway 영향을 식별한다.
- 외부 API, 메시지, 캐시와 설정 영향을 식별한다.
- 요청 범위 밖의 리팩터링과 기술 부채를 분리한다.

## Output Contract

- 분석한 요구사항과 코드 범위
- 읽은 Architecture와 Testing 문서 경로
- 확인한 코드 경로와 현재 책임
- 변경 대상 모듈, 계층, 공개 계약과 파일 후보
- 요구사항과 코드 변경 책임의 대응 관계
- 필요한 테스트 종류와 검증 환경
- Entity, Repository, 스키마와 Flyway 영향
- Infra와 외부 계약 영향
- 보존할 동작과 회귀 위험
- 범위 밖 변경과 미해결 사항
- 분석 완료 상태

## Verification Gate

- [ ] 확정된 요구사항만 분석 입력으로 사용했는가?
- [ ] `architecture-directory.md`를 끝까지 읽었는가?
- [ ] 관련 Architecture와 Testing 문서를 끝까지 읽었는가?
- [ ] 관련 코드 구조와 실행 경로를 확인했는가?
- [ ] 요구사항을 코드 변경 책임과 연결했는가?
- [ ] 테스트와 검증 환경을 식별했는가?
- [ ] Entity, Repository, Flyway와 Infra 영향을 판별했는가?
- [ ] 사실과 기술적 추론을 구분했는가?
- [ ] 코드와 문서를 수정하지 않았는가?

하나라도 확인하지 못하면 분석 완료로 처리하지 않는다.

## Failure Policy

- 필수 문서나 코드를 읽지 못하면 누락 경로를 보고하고 중단한다.
- 도메인 규칙이 미확정이면 분석 가능한 범위만 전달하고 대기한다.
- 변경 범위를 근거와 연결하지 못하면 확정 상태로 출력하지 않는다.
- 여러 구현 경로의 영향이 다르면 선택하지 않고 차이를 보고한다.
- 실행할 수 없는 검증은 이유와 미검증 범위를 기록한다.

## Exit Criteria

- 완료: 확정 요구사항을 검증 가능한 코드 변경 범위로 변환했다.
- 대기: 도메인 결정, 기술 선택 또는 추가 정보가 필요하다.
- 실패: 문서·코드 로딩이나 필수 분석을 완료할 수 없다.
- 취소: 사용자가 분석을 취소했다.
