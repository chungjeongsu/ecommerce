# User 도메인

## Aggregate

`User`가 Root Aggregate다.

```text
User
├─ UserRole
└─ UserStatus
```

## 책임

- 사용자 식별과 계정 정보 관리
- 이메일 중복 가입 방지
- 인증 정보 관리
- 구매자·판매자 역할 관리
- 사용자 권한의 기준 제공
- 회원 탈퇴 시 사용자 정보를 논리 삭제한다.
- 논리 삭제된 사용자의 주문·결제 이력은 보존한다.

## 인증 방식

Redis를 공유 저장소로 사용하는 서버 세션 기반 인증을 사용한다.

- 로그인 성공 시 예측할 수 없는 Session ID를 생성하고 Redis에 세션을 저장한다.
- 세션에는 사용자 식별과 권한 확인에 필요한 최소 정보만 저장한다.
- Session ID는 Cookie로 전달한다.
- Cookie는 `HttpOnly`, `Secure` 설정을 적용한다.
- 사용자와 Session ID는 1:N 관계로 관리한다.
- 브라우저·장치별 세션은 서로 독립적으로 관리한다.
- 로그아웃 시 현재 세션을 서버에서 무효화하고 Cookie 삭제를 요청한다.
- 사용하지 않는 세션은 마지막 요청 이후 30분이 지나면 만료한다.
- 세션은 로그인 후 8시간이 지나면 요청 여부와 관계없이 절대 만료한다.
- 동시 세션 수는 제한하지 않는다.
- 비밀번호는 BCrypt 단방향 해시로 저장한다.
- 비밀번호 원문과 복호화 가능한 형태의 비밀번호를 저장하지 않는다.
- 비밀번호는 최소 7자 이상이어야 한다.
- 비밀번호는 최대 8자 이하여야 한다.
- 로그인 실패 횟수 제한과 계정 잠금은 적용하지 않는다.

## Aggregate와 불변식

도메인 테스트는 Aggregate 내부 객체부터 Root Aggregate 순서로 작성한다.

```text
객체 내부 불변식
        ↓
Root Aggregate 불변식
        ↓
Application 외부 불변식
```

### 객체 내부 불변식

- 이메일은 기본적인 이메일 형식(`local-part@domain`)을 만족해야 한다.
- 사용자 이름은 필수이며 비어 있거나 공백일 수 없다.
- 사용자 이름은 최소 2자, 최대 6자여야 한다.

### Root Aggregate 불변식

- 사용자는 `BUYER` 또는 `SELLER` 역할을 가진다.
- 사용자 역할은 생성 시 결정하며 가입 후 변경할 수 없다.

### Application 외부 불변식

#### RegisterUserUsecase

- 동일한 이메일이라도 역할이 다르면 가입할 수 있다.
- 동일한 이메일과 동일한 역할 조합으로는 중복 가입할 수 없다.
- `WITHDRAWN` 사용자가 사용했던 이메일로는 다시 가입할 수 없다.
- 이메일은 입력된 문자열을 그대로 비교하며, 대소문자나 공백을 임의로 정규화하지 않는다.
- 비밀번호는 BCrypt 해시 형태로 저장한다.
- 비밀번호는 7자 이상 8자 이하여야 한다.

#### UpdateUserUsecase

- 인증 정보와 비밀번호 원문을 외부에 노출하지 않는다.
- 인증된 사용자는 자신의 정보만 조회할 수 있다.
- 인증된 사용자는 자신의 사용자 이름만 변경할 수 있다.
- 사용자 이름 변경 시에도 2~6자와 공백 불가 규칙을 적용한다.

#### ChangePasswordUsecase

- 인증된 사용자는 본인 인증 후 자신의 비밀번호를 변경할 수 있다.
- 비밀번호 변경 시에도 7~8자와 BCrypt 해시 규칙을 적용한다.

#### AuthorizeUserUsecase

- 판매자는 자신의 상품과 재고를 관리할 수 있다.
- 구매자는 주문과 결제를 요청할 수 있다.
- 다른 사용자의 주문·정산 정보에 무단 접근할 수 없다.
- 논리 삭제된 사용자는 로그인하거나 새로운 기능을 사용할 수 없다.

## 상태

```text
ACTIVE → WITHDRAWN
```

- 회원가입한 사용자는 `ACTIVE` 상태로 시작한다.
- 회원 탈퇴 시 `WITHDRAWN` 상태로 변경한다.
- `WITHDRAWN` 상태에서 `ACTIVE`로 되돌릴 수 없다.

## 주요 행위

- 회원가입
- 로그인
- 로그아웃
- 사용자 정보 조회
- 사용자 권한 확인

## 주요 속성

| 객체 | 속성 |
| --- | --- |
| User | id, name, email, passwordHash, role, status |
| UserRole | BUYER, SELLER |
| UserStatus | ACTIVE, WITHDRAWN |
